В проекте реализованы автоматизированные тесты для API учебного сервиса Яндекс Самокат.
Тесты проверяют следующие части сервиса:
- Создание курьера
- Авторизация курьера
- Создание заказа
- Получение списка заказов
- Обработка ошибок при отсутствующих или неправильных данных

Установка зависимостей: pip install -r requirements.txt

Запуск тестов: pytest -v tests

В проекте содержится Allure-отчет, для просмотра необходимо выполнить команду allure serve allure-results
